🌍 世界リサーチ(テーマから情報収集 → 解析 → 提案)

調べたいテーマと国・地域を選ぶだけで、各国の現地語で Web とニュースを集め、AI(aruaru-llm の無料 AI)がトレンド・機会・リスク・具体的な提案をまとめます。

1. データを読み込む

検索は aruaru-llm 経由で行います(キーは aruaru-llm の設定を共有)。結果のタイトル・URL・説明・スター数などを表にします。

CSV・JSON・HTMLの表を自動で読み取ります。表が無いページはリンク一覧を表にします。社内ネットワークのアドレスは取得しません。

2. 分析する

選んだデータセットを aruaru-db に保存し、その時点を「版」として記録します。あとから過去の版を読み込み直して、当時の分析をそのまま再現できます(再起動しても消えません)。
